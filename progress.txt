# HabitFlow Engineering Progress Log (Ralph Pattern)

## Codebase Patterns
- Build pipeline: Vite + Tailwind v4 + React 19 + TypeScript.
- Clean Architecture: No heavy WebGL / Three.js canvas in core productivity views. All animations must use hardware-accelerated Framer Motion spring physics.
- Offline-First: All calculations (momentum, streaks, correlations) must run in-memory and persist to Dexie IndexedDB before syncing to cloud.
